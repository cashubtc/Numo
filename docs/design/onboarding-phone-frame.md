# Onboarding handset asset

## Customer iPhone and wallet screen

`onboarding_iphone_frame.webp` is an independently generated iPhone-style photographic frame with a wide camera notch. Its alpha is preserved through lossless WebP conversion. `onboarding_customer_wallet.webp` is a lossless conversion of the wallet screenshot supplied by the user on 2026-09-08. Native Canvas composites that screenshot intact into the customer iPhone, including the Ready to Scan sheet. The reference wallet's EUR balances are part of the supplied screenshot; the authored Numo USD amounts use the separately fixed onboarding rate.

## Merchant Android frame

Generated with the built-in image-generation tool, then losslessly converted to WebP with its alpha preserved. The handset frame ships in `app/src/main/res/drawable-nodpi/onboarding_phone_frame.webp`. The screen is rendered separately from Numo's native layout resources.
